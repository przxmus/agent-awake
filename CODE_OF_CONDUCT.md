# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work.
Harassment, insults and personal attacks aren't tolerated in issues, pull requests,
discussions or anywhere else the project lives.

## Reporting

If someone's behavior bothers you, report it privately to the maintainer,
[@przxmus](https://github.com/przxmus), using the contact listed on their GitHub
profile. Reports are kept confidential.

The maintainer may edit or remove comments, close threads, and block people who
break these rules, as described in the Contributor Covenant enforcement guidelines.
